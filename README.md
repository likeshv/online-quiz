The Online Quiz and Examination System is a web-based application developed to make the process of conducting quizzes and examinations easier, faster, and more efficient. The website provides an interactive platform where students can register, log in, participate in online examinations, and evaluate their academic knowledge.

The website is developed using HTML, CSS, and JavaScript, providing a responsive and user-friendly interface that works across desktops, tablets, and mobile devices.

The system includes a landing page that introduces the website and displays its main features. Students can create an account through a registration form with input validation and securely access their accounts using the login page. The website also provides a quick sign-up option for convenient access.

After logging in, students are directed to a personalized dashboard where they can access available quizzes, view their previous examination results, and monitor their performance. The quiz section contains multiple-choice questions with a countdown timer. Once the quiz is completed or the timer expires, the system automatically calculates the score and displays the results.

The website also includes an interactive chatbot that helps students by providing answers to common queries using keyword-based responses. A built-in calculator is available for basic mathematical calculations. Additionally, the website supports light and dark themes, allowing students to customize their viewing experience. The selected theme is saved using browser storage.
